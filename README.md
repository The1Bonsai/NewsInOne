# NewsInOne

## Product Overview
NewsInOne is an innovative news aggregation platform that allows users to access news articles from multiple sources in one place. The platform aims to simplify the news reading experience by providing a clean, intuitive interface and personalized content delivery.

## Features
- **Multi-source Aggregation:** Access articles from various reputable news sources, ensuring diverse perspectives.
- **Personalized Feed:** Users can customize their news feed based on interests and preferences.
- **Real-time Updates:** Stay updated with the latest news as it happens.
- **Bookmarking Articles:** Save interesting articles for later reading.
- **Search Functionality:** Easily find specific topics or articles within the database.
- **User Accounts:** Create and manage your account for a tailored experience.

## Tech Stack
- **Frontend:** React.js, Redux, CSS
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **API:** RESTful API to handle requests and responses

## Setup Instructions
1. **Clone the repository:**  
   `git clone https://github.com/The1Bonsai/NewsInOne.git`

2. **Navigate to the project directory:**  
   `cd NewsInOne`

3. **Install dependencies:**  
   For the frontend:  
   `cd client`  
   `npm install`  
   
   For the backend:  
   `cd server`  
   `npm install`

4. **Run the application:**  
   For the frontend:  
   `npm start`  
   
   For the backend:  
   `nodemon server.js`

5. **Open your browser and navigate to:**  
   `http://localhost:3000`
